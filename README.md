# Game-Theoretic Network IDS

Course project for **Game Theory** (MA14363), Isfahan University of Technology, Spring 2025, Dr. Narimani.

The report treats an IDS and one or more attackers as a non-cooperative zero-sum game. The defender has a limited sampling budget on router interfaces; the attacker chooses paths on a flow network. A minimax argument gives the optimal sampling mix, and that mix sits on max-flow / min-cut bottlenecks. The writeup also covers cooperating attackers and compares the game-theoretic sampler with random and uniform sampling.
